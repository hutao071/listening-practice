# 「听一页」测试记录

测试日期为 2026 年 11 月 7 日。使用 Windows、Node.js 24.22.1 和 Codex 内置 Chromium 浏览器。

## 自动测试

运行 `node --test`，5 项通过。覆盖 3 秒跳转与边界、英文及中文独立揭示与重置、语料字段和编号校验、首批三个录音文件的存在性，以及真实 MP3 的 HTTP Range 读取。另核对缺失文件、非法范围及越出站点目录的请求均返回预期状态。服务端和页面脚本均通过语法检查。

用不含 Node 的 Windows PATH 运行 `start.cmd`，确认它能找到 Codex 自带的 Node 并在默认端口启动。首页返回 HTTP 200。

## 浏览器验证

| 场景 | 结果 |
| --- | --- |
| 选篇与文本 | 初次加载不自动播放，全部遮挡。Enter 揭开指定英文，空格揭开对应中文，再次点击可遮挡。切篇后归零并重新遮挡。 |
| 播放与拖动 | 三篇都能加载并进入播放状态。验证暂停、拖动进度、自然播完、从零重播及播放中切篇。 |
| 方向键 | 页面左右键分别跳转 3 秒，进度滑块有焦点时只跳一次。暂停时跳转仍保持暂停。 |
| 音频失败 | 本地测试服务对首篇音频第一次请求返回 404。页面提示失败并禁用播放。点击重试后恢复并可以播放。 |
| 响应式 | 模拟 375、768、1440 像素视口，练习页没有横向溢出。播放器三枚按钮均为 45 像素高。375 像素下选篇后目录自动收起，前进、后退按钮可用。 |

移动端为桌面浏览器视口模拟，未在真实手机上测试。浏览器主动拒绝 `play()` 的分支已实现提示，未单独注入该类拒绝。验收环境为本机。

## 音频兼容性修复复测

三篇内置录音改用 PCM WAV。选篇后可立即点击播放，拖动和跳转在音频时长就绪后启用。通过 `start.cmd` 启动后逐篇确认播放进度实际前进，且可以暂停并后退。临时测试服务关闭预加载，并令第二篇第一次请求返回 404。浏览器中确认仍可首次点击播放，失败时出现重试与单独打开音频的入口，重试后再次点击可播放。重新运行 `node --test`，5 项通过，其中服务测试核对了三份 WAV 的 PCM 文件头、媒体类型及字节范围响应。

## 用户验收

启动网页后选一篇并播放，确认首次进入看不见双语文本。按左方向键回退 3 秒，只揭开第一段英文，再独立揭开和收起中文。随后切到另一篇，确认旧音频停止，进度归零，双语再次遮挡。
