# 「听一页」四级听力练习工具开发方案

为个人四级备考提供本机响应式网页。首批 3 篇真题，练习过程为选篇、盲听、按需揭示某段英文或中文、回退重听。

## 页面与操作

- 暖白纸色、墨绿和橙色标记。桌面为目录与练习区双栏，窄屏为单列可收起目录。
- 初始提示选篇。切换时停掉旧音频，归零并重新遮挡全部文本。选择时不自动播放。
- 播放器支持播放、暂停、拖动、显示当前时间与总时长。加载有提示，失败可重试。左右方向键及对应触摸按钮各跳转 3 秒，限制在音频边界内，保留原播放状态。滑块焦点下只处理一次。编辑控件和上下键保留原行为。
- 每段英文及中文独立切换。使用可聚焦的按钮和实际隐藏状态，支持 Tab、Enter、空格。切换文字不改变播放位置。

## 实现与素材

- 原生 HTML、CSS、JavaScript 与浏览器音频。Node 本地静态服务仅监听回环地址，支持音频 Range。提供 Windows 双击入口。
- JSON 保存编号、标题、考试时间、题型、本地音频路径、来源、翻译来源与有序双语段落。
- 先联网核实可获取的真题、录音与原文并逐篇配对。缺少译文时自行补译并标注。只使用正常可下载材料。若无法取得完整素材，请用户提供本地音频及原文。模拟音频只供内部测试。
- 第一版在本机使用，聚焦听力与文本对照。技术参考：[MDN HTMLMediaElement](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement)。

## 开发与验收

1. 保存确认过的方案，核实并整理首批素材。
2. 实现目录、播放器、逐段遮挡和键盘操作。
3. 用 Node 内置测试覆盖时间边界、遮挡状态与语料结构。浏览器实测播放、暂停、拖动、重播、快速切换、键盘、错误重试和遮挡。检查 375、768、1440 像素布局，区分模拟和实机结果。
4. 交付启动入口、使用说明和测试记录，请用户实操验收。完整语料验收需三篇真实音频、匹配原文和中文翻译。交互验收路径为选篇、盲听、回退 3 秒、单独揭示一段英文和中文、重新遮挡。
