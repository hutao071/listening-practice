# 听一页

一个在本机练习四级听力的网页。首册有 2024 年 6 月四级第二套的三篇短篇新闻，音频、英文和中文都保存在项目中，启动后可离线练习。

## 打开练习册

1. Windows 双击 `start.cmd`，或在项目目录运行 `node server.mjs`。双击启动时可使用系统 Node.js 或 Codex 自带的 Node.js，无需运行 npm 安装依赖。
2. 保持启动窗口打开，在浏览器访问 [本机练习册](http://127.0.0.1:4173/)。
3. 从目录选一篇，再点击播放。左右键或播放器两侧的按钮可以后退、前进 3 秒。想核对时，点击某段的英文或中文标题，再点一次收起。
4. 按 Ctrl+C 或关闭启动窗口结束本机服务。

## 语料

英文以新东方整理的第二套文本为底稿，修正明显断字和标点，并按录音顺序分段。中文为本项目补译。录音取自公开题库页面，题库标号与文本来源的套次标注不同，项目以内容核对后的第二套标注为准。练习音频保留三段新闻正文。[英文原文来源](https://cet4.koolearn.com/20240615/906277.html) · [录音来源页面](https://zhenti.burningvocabulary.cn/cet4/2024-06/01)

要增加材料，可把 MP3 或 WAV 放入 `public/audio/`，参照 `public/library.json` 添加一条篇目记录。音频文件名使用小写字母、数字和连字符，英文和中文以相同段落顺序填写。

运行 `node --test` 可执行自动测试。测试需要允许 Node 连接本机回环地址。验收过程见 `docs/测试记录.md`。
